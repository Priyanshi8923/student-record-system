# Student Record Management System

A command-line based Python application to manage student records efficiently. Built for the Python Essentials course project.

## Features
- Add new student details (Roll Number, Name, Course, Marks)
- View all saved student records in a structured format
- Search for a specific student using their Roll Number
- Data persistence using text file storage (`students_data.txt`)

## Prerequisites
- Python 3.x installed on your system.
